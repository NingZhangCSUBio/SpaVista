SpaVista Documentation
======================

SpaVista is an H&E image encoder for spatially resolved molecular analysis. This documentation covers installation, a small evaluation demo, feature extraction, and five downstream workflows.

The `source code <https://github.com/NingZhangCSUBio/SpaVista>`_ is on GitHub. The `encoder checkpoint and companion data <https://huggingface.co/ZNfiona1997/SpaVista/tree/main>`_ are distributed through Hugging Face.
